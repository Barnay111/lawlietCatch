# DemoBank — тестовый мобильный банк

Учебное приложение на Expo (React Native, TypeScript) для проверки BehaviorGuard SDK.
Не настоящий банк: все деньги, счета и справочники условные и живут в памяти приложения (`src/lib/bank.ts`).

## Что есть

| Раздел | Экраны | Что делает |
|---|---|---|
| Вход | `app/index.tsx` | Псевдоним клиента, обязательное согласие на анализ поведения |
| Главная | `app/(tabs)/home.tsx` | Общий баланс, счета, быстрые действия, последние операции |
| Переводы | `app/(tabs)/transfers.tsx` | Меню переводов |
| — по карте | `app/transfer/card.tsx` | Номер карты проверяется алгоритмом Луна |
| — по телефону | `app/transfer/phone.tsx` | Формат +7, поиск получателя в учебном справочнике |
| — между счетами | `app/transfer/own.tsx` | «Мой банк»: свои счета без комиссии |
| — по QR | `app/transfer/qr.tsx` | Камера распознаёт `bankqr://…`; вручную, если камеры нет |
| — получить | `app/transfer/receive.tsx` | Свой QR-код для получения денег |
| Платежи | `app/(tabs)/payments.tsx`, `app/payments/*` | Категории: связь, ЖКХ и интернет, госуслуги, путешествия |
| Сообщения | `app/(tabs)/messages.tsx` | Уведомления банка, безопасность, акции |
| Ещё | `app/(tabs)/more.tsx` | Согласие на анализ, состояние SDK, выход |

## Что настоящее, а что нет

**Настоящее (с точки зрения SDK и поведения):** все экраны отправляют сигналы BehaviorGuard. Поля номера карты,
телефона, логина и ИИН помечены как чувствительные: SDK по ним ничего не собирает. Экраны отмечаются
технически (`transfer.card`, `payments.gov`), без данных.

**Моки:** баланс, переводы, справочник получателей, каталог услуг, QR-коды. Реальной платёжной системы нет,
подтверждения операций через СМС и PIN пока не сделаны.

**Важно для безопасности:** оценка риска (`POST /api/v1/risk/assess`) вызывается бэкендом банка с серверным ключом.
Мобильное приложение серверный ключ не хранит. В демо оценка риска на экранах переводов не подключена.

## Запуск

```bash
cd demo-bank
npm install
cp .env.example .env.local   # заполнить EXPO_PUBLIC_BG_API_KEY ключом SDK
npx expo run:ios --device "iPhone 17" --no-bundler   # первая сборка dev-клиента
npx expo start --dev-client --port 8081
```

Камера и QR требуют dev-клиента (`expo-camera`). В Expo Go они не работают.

Для снимков экрана в разработке: `EXPO_PUBLIC_DEMO_AUTOLOGIN=1` включает вход без экрана логина.
Работает только в `__DEV__`, в пользовательских сборках отключено.
